# フロントエンド i18n 方針

## 1. 目的

フロントエンドを日本語と繁体字中国語の2言語で利用できるようにし、画面に表示する文言を一元管理する。

対象ロケールは次の2つとする。

| locale | 言語 |
| --- | --- |
| `ja` | 日本語 |
| `zh-TW` | 繁体字中国語 |

実装には `vue-i18n` を使用する。

## 2. 実装場所

翻訳メッセージは次のファイルで管理する。

```text
web/src/i18n/index.ts
```

`main.ts` でi18nプラグインを登録し、各ページ・コンポーネントでは `useI18n()` の `t()` を使用する。

```ts
import { useI18n } from 'vue-i18n'

const { t } = useI18n()
```

テンプレートでは、表示文言を直接書かず翻訳キーを参照する。

```vue
<h1>{{ t('students.title') }}</h1>
<UButton :label="t('students.add')" />
```

## 3. 言語切り替え

- ログイン画面では、システム名の直下に言語セレクターを表示する。
- ログイン後は、共通ヘッダー右上に言語セレクターを表示する。
- 選択値は `ja` または `zh-TW` のみ許可する。
- 選択したロケールは `localStorage` の `portfolio-locale` に保存する。
- 初回表示時は保存値を読み込み、未保存または不正値の場合は `ja` を使用する。
- 翻訳が不足している場合のフォールバックは日本語とする。

## 4. 翻訳キーの命名

翻訳キーは画面・機能単位で階層化する。

```text
app.*          アプリ共通
common.*       ボタン、状態、共通ラベル
nav.*          ナビゲーション
dashboard.*    ダッシュボード
students.*     生徒機能
teachers.*     講師機能
lessons.*      レッスン機能
login.*        ログイン
```

同じ意味の文言は、既存の `common.*` キーを優先して再利用する。画面固有の文言だけを各機能配下へ追加する。

## 5. 新機能追加時の必須ルール

今後、新しい画面・コンポーネント・モーダル・フォーム・エラー表示を追加する場合、表示文言は必ずi18n化する。

### 必須対応

1. 日本語（`ja`）と繁体字中国語（`zh-TW`）の両方に翻訳キーを追加する。
2. Vueテンプレートの固定文字列ではなく、`t('...')` を使用する。
3. `aria-label`、`title`、`placeholder`、空状態、ローディング、エラー、確認ダイアログも翻訳対象にする。
4. 表示する日時・曜日・数値は、現在のロケールに合わせてフォーマットする。
5. 状態値やAPIの内部値（例：`scheduled`、`completed`）をDBやAPIから直接画面表示しない。
6. 追加後に日本語・繁体字中国語の両方で型チェックと画面確認を行う。

### 禁止事項

```vue
<!-- 禁止：画面に日本語を直接記述する -->
<UButton label="生徒を追加" />

<!-- 禁止：localeによる条件分岐を各コンポーネントに分散する -->
{{ locale === 'ja' ? '生徒' : '學生' }}
```

次のように書く。

```vue
<UButton :label="t('students.add')" />
{{ t('students.title') }}
```

## 6. 日付・数値の表示

日時は `Intl.DateTimeFormat` などへ現在のロケールを渡して表示する。

```ts
const formattedDate = new Intl.DateTimeFormat(locale.value, {
  dateStyle: 'medium',
}).format(date)
```

API・DBに保存する日時は既存方針どおりISO 8601 / UTCを使用し、翻訳や表示ロケールを保存値に混在させない。

## 7. 確認方法

変更時は次を実行する。

```bash
pnpm --dir web type-check
pnpm --dir web build
```

画面確認では、少なくとも次を確認する。

- ログイン画面で言語を切り替えられる
- ログイン後のヘッダーでも切り替えられる
- ページタイトル、ナビゲーション、ボタン、フォーム、エラー、空状態が切り替わる
- 再読み込み後も選択言語が維持される
- 2言語のどちらでも文言が未翻訳キーのまま表示されない

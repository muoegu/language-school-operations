# 通知センター

## 目的

ダッシュボードに表示していた本日のレッスン予定と顧客アラートを、システムヘッダーの通知アイコンから確認できるようにする。

## 表示内容

| ロール | 通知内容 |
| --- | --- |
| 代表 | 本日のスケジュール、顧客アラート |
| 講師 | 自分が閲覧できる本日のスケジュール |
| スタッフ | 閲覧できる本日のスケジュール |

顧客アラートは既存の`GET /api/v1/dashboard/alerts`を利用し、代表だけが取得する。スケジュールは既存の`GET /api/v1/lessons`を利用し、API側のロール・担当範囲による絞り込み結果から当日分を抽出する。

## UI

- `NotificationCenter.vue`をヘッダーへ配置
- ベルアイコンのバッジに未確認件数を表示
- ポップオーバー内で「本日のスケジュール」と「顧客アラート」を分けて表示
- レッスンを選択するとレッスン詳細へ移動
- 顧客アラートを選択すると生徒一覧へ移動
- APIエラー時と通知0件時の表示を用意

通知は既読状態を持たない簡易表示とする。既読管理が必要になった場合は、通知専用テーブルまたはユーザー単位の既読記録を追加する。

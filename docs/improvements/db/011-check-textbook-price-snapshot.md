# DB改善 011: 教科書価格スナップショットの負数防止

## 目的

支払い記録に紐付く教科書価格は、購入時点の価格を履歴として保持する。元の教科書データが正しくても、履歴側に負数が入ると請求金額と支払い記録の整合性が崩れるため、データベースでも負数を拒否する。

## 変更内容

- `payment_record_textbooks.price_minor_snapshot >= 0` のCHECK制約を追加

## 互換性

既存の正常な支払い記録には影響しない。APIレスポンスは変更しない。

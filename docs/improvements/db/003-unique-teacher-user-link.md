# DB改善 003: ユーザーと講師プロフィールの1対1制約

## 目的

ログインユーザーと講師プロフィールは原則1対1で運用する。現在の`teachers.user_id`には一意制約がなく、同じユーザーに複数の講師プロフィールを関連付けられる状態だった。

## 変更内容

- `teachers.user_id` にNULLを除外した一意インデックスを追加
- `user_id`がNULLの未ログイン講師プロフィールは複数登録可能

## 互換性

既存のAPI形式は変更しない。既存データに重複した`user_id`がないことを前提に適用する。

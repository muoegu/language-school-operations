# DB改善 012: 終了済み担当割当の終了日時を必須化

## 目的

担当割当は`is_active`で現在の状態を、`ended_at`で履歴上の終了日時を表す。終了済みなのに終了日時がない行を許すと、担当期間の表示や監査で状態を復元できないため、両方の値を整合させる。

## 変更内容

- `is_active = false` の担当割当では `ended_at` を必須にするCHECK制約を追加

## 互換性

現在有効な割当には影響しない。終了処理は終了日時を設定する必要があり、APIの更新処理で既存の終了日時を保持する。

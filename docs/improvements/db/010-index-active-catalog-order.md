# DB改善 010: 有効状態と表示順の複合インデックス

## 目的

生徒・講師・クラス・教科書の一覧APIは、有効状態や販売状態で絞り込みながら名前・タイトル順に並べる。単独インデックスだけでは絞り込みと並び替えを同時に最適化しにくいため、実際の一覧条件に合わせる。

## 変更内容

- 生徒: `is_active, display_name`
- 講師: `is_active, display_name`
- クラス: `is_active, name`
- 教科書: `status, title`

## 互換性

APIのレスポンスとソート順は変更しない。インデックス追加のみである。

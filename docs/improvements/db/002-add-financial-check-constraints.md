# DB改善 002: 金額・授業時間のCHECK制約

## 目的

APIの入力検証を通らない経路や将来のバッチ処理からも、負の金額・0分の授業・内訳と合計が一致しない支払い記録を登録できないようにする。

## 変更内容

- クラスの授業時間を1分以上に制限
- クラス・教科書の価格を0以上に制限
- 支払い記録の授業料・教科書代・合計金額を0以上に制限
- 支払い記録の合計金額を「授業料 + 教科書代」に一致させる

## 互換性

既存のAPIレスポンスと入力形式は変更しない。既存シードの値は制約を満たすため、データ移行は不要。

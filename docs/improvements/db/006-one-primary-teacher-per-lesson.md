# DB改善 006: レッスンの主担当講師を1人に制限

## 目的

レッスンには複数講師を紐付けられるが、主担当講師は1人という既存のアプリルールをDBでも保証する。現在は`primary`が複数登録できる状態だった。

## 変更内容

- `lesson_teachers.lesson_id`に`role = 'primary'`の部分一意インデックスを追加
- `assistant`講師は複数登録可能

## 互換性

既存のレッスン登録APIの形式は変更しない。現在の参加者置換処理が作る主担当1人・アシスタント複数の構造と一致する。

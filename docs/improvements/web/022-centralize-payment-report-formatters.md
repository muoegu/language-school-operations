# Web追加改善 022: 支払いレポートのフォーマッター統一

## 目的

支払いレポートだけが`Intl.NumberFormat`と`Intl.DateTimeFormat`を直接生成していた。既存の共通フォーマッターへ移し、画面間の表示仕様を統一する。

## 変更内容

- 支払いレポートの通貨表示を`formatCurrency`へ移行
- 購入日の表示を`formatDateTime`へ移行

# Web改善 002: 権限外APIクエリの抑制

## 目的

API側で権限を正しく制限した後も、スタッフや講師の画面が代表専用APIを呼び出して403を発生させる箇所が残っていた。権限のないデータを取得しようとせず、画面の表示も権限に合わせる。

## 変更内容

- スタッフのダッシュボード・レッスン画面で生徒／講師APIを呼ばない
- 講師のレッスン画面では担当生徒APIのみ利用する
- 講師の生徒詳細から支払い記録・教材・請求情報を非表示
- 請求書印刷URLを代表専用にする

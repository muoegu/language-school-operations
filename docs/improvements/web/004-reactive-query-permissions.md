# Web改善 004: 権限付きクエリ条件のリアクティブ化

## 目的

権限付きVue Queryの`enabled`へ、画面初期化時のboolean値を渡していた。認証状態が切り替わってもクエリ条件が更新されないため、computed/refをそのまま渡して状態とデータ取得条件を同期する。

## 変更内容

- 生徒・講師・支払い関連クエリの`enabled`へリアクティブな値を渡す
- 代表／講師の複合条件をcomputed化
- APIや画面仕様は変更しない

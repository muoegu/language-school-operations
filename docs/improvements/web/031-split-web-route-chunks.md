# Web追加改善 031: ルート分割と本番ビルド最適化

## 目的

Webビルドで初期バンドルが大きくなり、チャンクサイズ警告が発生していた。初回表示に不要なページや開発用ツールまで本番バンドルへ含まれていたため、初期読み込みとWorker配信時の負荷を下げる。

## 変更内容

- Vue Routerの各ページをルート単位の遅延読み込みへ変更
- Vue DevToolsを開発モードでのみ有効化
- 本番ビルドの大きな単一チャンクをページ・依存コンポーネント単位へ分割

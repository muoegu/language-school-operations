# Web改善 008: 権限外の管理操作を表示しない

## 目的

API側で代表者限定となっている講師・料金・教科書・支払い操作について、先生やスタッフの画面に編集・削除・購入ボタンを表示しない。表示だけでなく、権限外の一覧取得も実行しない。

## 変更内容

- 講師画面を`canManageTeachers`に連動
- 料金・教科書画面を`canViewPaymentData`に連動
- 生徒詳細の支払い操作と請求書操作を代表者だけに表示
- 対象のTanStack Queryを権限がある場合だけ有効化

# Web改善 003: APIエラー解析の共通化

## 目的

レッスン詳細と請求書画面がAPIエラーの内部構造を個別に型キャストしており、エラー形式の変更時に修正漏れが起きやすい。共通ヘルパーでコードとメッセージを取り出す。

## 変更内容

- `getApiErrorCode`を追加
- `getApiErrorMessage`を追加
- レッスン記録保存エラーと請求書エラーで共通ヘルパーを利用

## 互換性

既存のエラー表示文言とAPIリクエストは変更しない。

# Web改善 011: ルート権限メタデータを型付け

## 目的

ルート権限メタデータを文字列として扱うと、存在しない権限名の入力をコンパイル時に検出できない。Vue Routerの`RouteMeta`を拡張し、既存のルートガードとルート定義を型安全にする。

## 変更内容

- `RouteMeta.permission`を許可された3種類の権限に限定
- ルートガードの不要な型キャストを削除

## 互換性

画面遷移と権限判定は変更しない。権限名の誤記だけを型チェックで検出できるようになる。

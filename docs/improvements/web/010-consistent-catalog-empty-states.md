# Web改善 010: マスタ一覧の空状態表示を統一

## 目的

教科書・料金一覧は、取得後にデータが0件でも表だけが表示され、初期状態と空状態を区別しにくかった。既存の共通文言を使い、ロード完了後の空状態を明示する。

## 変更内容

- 教科書一覧に空状態メッセージを追加
- 料金一覧に空状態メッセージを追加
- ロード中・エラー中はメッセージを表示しない

## 互換性

データ取得、編集、削除の処理は変更しない。0件時の表示だけを改善する。

# Web改善 001: ロール権限判定の集約

## 目的

ナビゲーション、ルートガード、レッスン画面に同じロール判定が個別に書かれているため、権限ルールの変更時に判定がずれる可能性がある。既存のロール仕様を`useAuth`へ集約する。

## 変更内容

- `useAuth`に画面操作単位の権限computedを追加
- ルートガードとナビゲーションで共通権限を利用
- レッスン一覧・詳細の記録参照／スケジュール操作判定で共通権限を利用

## 互換性

画面に表示されるメニューと既存のアクセス制御ルールは維持する。APIの権限判定は変更しない。

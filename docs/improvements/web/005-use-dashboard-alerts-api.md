# Web改善 005: ダッシュボードアラートの実データ化

## 目的

代表ダッシュボードのアラートが固定データだったため、登録された生徒の未受講・未払い・誕生日情報を反映できていなかった。既存のDashboard Alerts APIを表示へ接続する。

## 変更内容

- 既存の`/dashboard/alerts` APIを利用
- 未受講・未払い・誕生日アラートを既存カードへ変換
- アラート取得失敗を既存のエラー表示へ統合
- 代表以外は権限外APIを呼ばない

# Web改善 009: ルート権限判定をメタデータ化

## 目的

ルートガードがURL文字列を直接比較して権限を判定していたため、詳細ルートや印刷ルートを追加するたびに条件分岐が増える状態だった。既存のルートに必要権限をメタデータとして持たせ、判定処理を一元化する。

## 変更内容

- 生徒・講師・教科書・料金・支払いレポート・請求書ルートに必要権限を設定
- `beforeEach`でルートメタデータと既存の権限computedを照合
- URLの前方一致や個別パス比較を削除

## 互換性

画面、権限、リダイレクト先は変更しない。既存のルートガードを同じ権限情報から評価するだけである。

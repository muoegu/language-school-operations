# API改善 012: ログイン処理のDBクライアント再利用

## 目的

デモログインでは、ユーザー検索とログイン後のユーザー取得で同じデータベースを使う。リクエスト内で`getDb`を複数回呼ばず、同じDBクライアントを明示的に再利用して処理の意図を分かりやすくする。

## 変更内容

- ログインハンドラーの先頭でDBクライアントを1回取得
- `loginAsDemoUser`と`getCurrentUser`へ同じクライアントを渡す

## 互換性

認証結果、Cookie、レスポンス形式は変更しない。DBクライアントキャッシュと組み合わせても、リクエスト内の依存関係が明確になる。

# API改善 004: 支払い記録APIの代表専用化

## 目的

支払い記録には請求金額、支払い状態、教材購入情報が含まれるため、スケジュール参照権限とは分離して代表だけが扱えるようにする。

## 変更内容

- 支払い記録の一覧・詳細に認証を追加
- 支払い記録の作成・更新・キャンセルを代表専用に変更
- 既存の支払い計算・チケット消費ロジックは変更しない

## 権限

- 代表: 参照・作成・更新・キャンセル
- 講師・スタッフ: 403
- 未認証: 401

# API改善 009: レッスン記録日時のサービス検証

## 目的

OpenAPIのスキーマ検証を通らない内部呼び出しや将来のバッチ処理でも、無効な日時がDB処理へ進まないようにする。

## 変更内容

- `actualStart`と`actualEnd`をDate変換後に検証
- 無効な日時を400の`VALIDATION_ERROR`として返す
- 既存の終了時刻順序チェックを維持
- 無効日時のテストを追加

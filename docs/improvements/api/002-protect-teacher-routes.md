# API改善 002: 講師CRUDの代表専用化

## 目的

講師プロフィールはユーザー権限を管理するマスターデータであるため、未認証ユーザーや講師・スタッフから変更できないようにする。

## 変更内容

- 講師一覧・詳細に認証を追加
- 講師の作成・更新・無効化を代表専用に変更
- API改善001で追加した共通ロール判定を再利用

## 権限

- 代表: 講師CRUDを実行可能
- 講師・スタッフ: 403
- 未認証: 401

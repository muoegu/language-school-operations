# API改善 007: 一覧APIのページング順序安定化

## 目的

ページング対象の一覧で表示名・タイトル・購入日時が同じレコードの順序をDBに任せていたため、ページ移動時に重複表示や取りこぼしが起きる可能性があった。

## 変更内容

- 生徒・講師・クラス・教科書一覧にIDを第2ソートキーとして追加
- 支払い記録一覧・支払いレポートにIDを第2ソートキーとして追加
- 既存の主ソート項目とレスポンス形式は維持

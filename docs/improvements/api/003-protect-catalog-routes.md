# API改善 003: クラス・教科書マスタAPIの権限保護

## 目的

クラスと教科書は請求・レッスン作成に使うマスターデータであり、未認証で参照・変更できる状態を解消する。

## 権限

- クラスの参照: 代表・講師・スタッフ
- クラスの作成・更新・無効化: 代表
- 教科書の参照・作成・更新・販売終了: 代表
- 未認証: 401

## 変更内容

- class/lesson-type APIに認証とロール判定を追加
- textbook APIに認証と代表権限判定を追加
- 既存のレスポンスとCRUD処理は維持

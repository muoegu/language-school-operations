# API改善 001: 生徒APIの認証・ロール保護

## 目的

生徒一覧の取得、作成、更新、無効化が未認証でも実行できる状態を解消する。既存の3ロール仕様をAPIの入口で一貫して適用する。

## 権限

- 代表: 全生徒の参照・作成・更新・無効化
- 講師: 担当生徒のみ参照
- スタッフ: 生徒APIへのアクセス不可

## 変更内容

- 生徒一覧にもセッション認証を追加
- 講師の生徒一覧を担当生徒へ限定
- 生徒の作成・更新・無効化を代表専用に変更
- 共通の`requireRole`ヘルパーを追加

## 互換性

既存の代表ユーザーの操作は維持される。未認証クライアントやスタッフからの生徒API呼び出しは403/401になる。

# API改善 013: セッション応答のキャッシュ禁止

## 目的

ログイン後のユーザー情報や担当生徒情報は、ユーザーごとに異なる。ブラウザや中間キャッシュに個人向け応答を保存させないため、セッション関連の応答に`Cache-Control: no-store`を付ける。

## 変更内容

- ログイン成功、ログアウト、`/me`、`/me/students`に`Cache-Control: no-store`を設定
- セッション情報を返すHTTP契約の確認を追加

## 互換性

レスポンス本文・Cookie形式・認証判定は変更しない。キャッシュされなくなるため、セッション切替時に古いユーザー情報が残りにくくなる。

# 語言學校業務管理系統

## 繁體中文

這是一個以作品集為目的開發的Web應用程式，用於集中管理語言學校的學生、教師、課程與付款資訊。

實際畫面：[https://portfolio.muoegu.org/](https://portfolio.muoegu.org/)

### 本機啟動

請在專案根目錄執行：

```bash
pnpm install
pnpm dev
```

`pnpm dev` 會同時啟動API與Web。Web位於 `http://localhost:5173`，API位於 `http://localhost:3000`。

### 使用者角色

- 代表：查看學校整體資訊、付款狀況與客戶提醒
- 工作人員：管理學生、教師與課程等日常業務
- 教師：管理自己負責的課程、課程記錄與下次課程內容

### 主要功能

#### 儀表板

查看課程行事曆、教師任務與客戶提醒。提醒包含近期沒有上課、付款逾期及生日將近的學生。

#### 學生與教師管理

可從列表新增、編輯及刪除學生與教師。學生詳細頁面可查看可用課程次數、付款記錄與教材資訊。

#### 課程管理

課程可以透過列表以及月、週、日行事曆查看，支援依標題、日期、教師、學生與狀態搜尋、篩選及排序。課程結束後可登錄實際時間、課程內容及下次作業，尚未完成的項目會顯示在儀表板任務中。

#### 教材與班級管理

管理課程中使用的教材與班級資訊。

#### 付款與課程券管理

以5堂課為1張課程券，依課程完成狀況扣除剩餘次數。可查看付款記錄、教材費、付款狀況圖表及PDF帳單。

#### 通知與權限管理

從通知查看今日課程與客戶提醒。課程記錄建立通知只會顯示給代表，畫面顯示與新增、編輯、刪除操作會依使用者角色限制。

### 技術架構

- Vue 3 / Vite / TypeScript
- Nuxt UI
- TanStack Query
- OpenAPI / Kubb
- Hono / Drizzle ORM
- PostgreSQL

API、Web與文件以Monorepo方式分離管理。前端使用OpenAPI產生的型別與Vue Query Composable，表單使用Zod與Nuxt UI FormField。

### 特色

#### 依角色控制畫面與操作

代表、工作人員與教師看到的選單及可執行操作不同。除了前端隱藏選單之外，API也會檢查權限，防止直接發送請求進行未授權操作。

#### 以業務流程為中心的資料連動

學生、課程、課程記錄、付款記錄與課程券餘額彼此連動。完成課程記錄後，對應任務會自動消失；尚未填寫下次課程內容時，會顯示準備任務。

#### 適合不同用途的課程顯示

列表支援搜尋、篩選與排序，行事曆則提供月、週、日三種檢視。月檢視顯示學生與教師姓名，日檢視依時間軸顯示課程安排。

#### 型別安全的API連接

使用Kubb從OpenAPI定義產生TypeScript型別與Vue Query Composable，讓API規格更容易同步到前端。

#### 可重複使用的管理介面

以Nuxt UI為基礎，共用表單、確認視窗、表格操作與提示工具等介面元件。

#### 多語言支援

透過i18n切換日文與繁體中文。畫面文字以翻譯鍵管理，方便未來新增其他語言。

## 日本語

語学学校の生徒・講師・授業・支払いなどを一元管理するポートフォリオ用Webアプリケーションです。

実際の画面：[https://portfolio.muoegu.org/](https://portfolio.muoegu.org/)

### ローカルでの起動

プロジェクトのルートで以下を実行します。

```bash
pnpm install
pnpm dev
```

`pnpm dev` でAPIとWebが同時に起動します。Webは `http://localhost:5173`、APIは `http://localhost:3000` です。

### 想定ユーザー

- 代表者：学校全体の情報、支払い状況、顧客アラートを確認
- スタッフ：生徒・講師・授業などの日常業務を管理
- 講師：担当授業と授業記録、次回レッスンの内容を管理

### 主な機能

#### ダッシュボード

授業カレンダー、講師向けタスク、顧客アラートを確認できます。アラートには、最近レッスンがない顧客、支払い期限を超過している顧客、誕生日が近い顧客を表示します。

#### 顧客・講師管理

生徒・講師の一覧から、新規作成・編集・削除を行えます。生徒詳細では、利用可能なレッスン数、支払い記録、教材情報を確認できます。

#### 授業管理

授業を一覧テーブルと月・週・日カレンダーで確認できます。タイトル、日時、講師、生徒、状態による検索・絞り込み、ソートに対応しています。授業後は実施時間、授業内容、次回の課題・内容を登録でき、未登録の項目はダッシュボードのタスクに表示されます。

#### 教材・クラス管理

授業で利用する教材とクラス情報を管理できます。

#### 支払い・チケット管理

5回分のレッスンを1チケットとして管理し、授業の実施に応じて残数を消化します。支払い記録、教材費、入金状況のグラフ、請求書PDFを確認できます。

#### 通知・権限管理

通知から本日の授業予定や顧客アラートを確認できます。授業記録の作成通知は代表者だけに表示します。画面表示と登録・編集・削除の操作はロールに応じて制御しています。

### 技術構成

- Vue 3 / Vite / TypeScript
- Nuxt UI
- TanStack Query
- OpenAPI / Kubb
- Hono / Drizzle ORM
- PostgreSQL

API・Web・ドキュメントを分離したモノレポ構成です。フロントエンドはOpenAPIから生成した型・Vue Query Composableを利用し、フォームにはZodとNuxt UIのFormFieldを使用しています。

### 特長

#### ロールに応じた画面表示と操作制御

代表者、スタッフ、講師で表示メニューや操作範囲が異なります。画面だけでなくAPI側でも権限を検証し、直接リクエストした場合も不正な操作を防ぎます。

#### 業務フローを意識したデータ連携

生徒、授業、授業記録、支払い記録、チケット残数を連動させています。授業記録を登録すると対応タスクから消え、次回内容が未入力の場合は準備タスクとして表示されます。

#### 用途に応じた授業表示

一覧テーブルと月・週・日のカレンダーを用途に応じて使い分けられます。月表示では生徒名と講師名、日表示では時間軸に沿った予定を確認できます。

#### 型安全なAPI連携

OpenAPI定義からKubbでTypeScriptの型とVue Query Composableを生成し、API仕様をフロントエンドへ反映しやすくしています。

#### 再利用しやすい管理画面UI

Nuxt UIをベースに、フォーム、確認モーダル、テーブル操作、ツールチップなどを共通化しています。

#### 多言語対応

i18nにより、日本語と繁体字中国語を切り替えて利用できます。画面文言は翻訳キーで管理し、言語追加にも対応しやすい構成です。
